# Awakening RPG Companion

Awakening RPG Companion is a Minecraft NeoForge mod for Minecraft 1.20.1 that transforms your game into a rich RPG adventure while remaining fully compatible with The Awakening combat mod. This mod adds an endless explorable dimension, epic RPG gear, and a quest tracking journal without ever touching combat mechanics — The Awakening remains the sole combat system. If you're looking for an RPG experience with endless exploration, a custom adventure dimension with unique gear, and a structured quest system that works alongside your favorite combat mod, this companion is designed to enhance every moment of your journey.

## Install

1. Install [NeoForge](https://neoforged.net/) for Minecraft 1.20.1 (NeoForge 47.x).
2. Download the mod jar file `awakening-rpg-1.0.0.jar`.
3. Place the jar file into the `mods` folder of your Minecraft directory (alongside other mods like The Awakening).
4. Launch the game with the NeoForge profile.

## Use

Once installed, you'll find all new items in the **Awakening RPG** creative tab. Here's how to use them:

1. **Wayfinder Compass** — Right-click to teleport between the Overworld and the newly added Awakening Lands dimension.
2. **Quest Tome** — Right-click to open the Adventure Journal, which tracks your RPG quests and guides your exploration.
3. **Aetherial Sword** — Equip and fight with this powerful fireproof blade. Combat behavior is handled entirely by The Awakening mod.

The Awakening Lands dimension is endlessly explorable with full terrain generation (based on Overworld settings with plains biomes). You can customize the dimension by editing the datapack files under `data/awakening_rpg/dimension/` and `data/awakening_rpg/dimension_type/` in the mod jar.
